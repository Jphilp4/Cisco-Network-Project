# Secure Enterprise Network Design - Cisco Packet Tracer

## Overview
Designed a scalable enterprise network using **Cisco Packet Tracer** with VLANs, QoS, STP, ACLs, and OSPF routing to ensure performance, security, and scalability.

## Technologies Used
- **VLANs**: Logical network segmentation
- **QoS**: Prioritisation of real-time traffic
- **STP**: Prevention of switching loops
- **ACLs**: Access control between departments
- **OSPF Routing**: Scalable routing for future expansion

## Challenge
Create a network that supports real-time traffic, prevents switching loops, enforces access control, and remains scalable.

## Solution
- Designed network using **VLANs** and **ACLs** for department separation and security.
- Applied **STP** to prevent loops and **QoS** to prioritise time-sensitive data.
- Configured **OSPF** for future scalability.

## Skills Developed
- **VLAN configuration**, **QoS**, **ACL setup**
- **OSPF routing**, **Network security**, **Troubleshooting**
